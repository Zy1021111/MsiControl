═══ 三、你的职责 ═══

负责 MsiControl.Monitoring（文件归属见任务书 §15.1）。

1. 单一共享采样
   整个应用只有 ONE 个采样任务，默认每 1 秒一次。窗口只订阅结果，
   不各自创建计时器读取硬件。控制在隐藏界面时不得中断。

2. CPU 四项
   温度（°C）、统一频率（内部 MHz）、封装功耗（W）、风扇百分比或 RPM。
   频率只显示一个统一数值，用 FrequencyAggregation 注明统计口径，
   默认 AverageActive（所有活跃核心时钟均值）。不拆分 P/E 核。

3. GPU 四项
   温度（°C）、核心频率（GHz 显示，内部 MHz）、功耗（W）、风扇。
   默认监控 RTX 5070 Ti 独显。

4. 双风扇
   RPM 与「校准后百分比」分开表达（FanReading 的 Rpm / ActualPercent / TargetPercent
   是三个不同字段，不得互相替代）。
   未完成有效校准时 ActualPercent 为 null，界面回落显示 RPM。

5. 整机功耗（独立子任务）
   独立调查本机是否存在可靠来源。三种口径用 PowerSourceKind 区分：
   BatterySide / AdapterInput / WallSocket，不可混用、不可相加。
   没有可靠来源时返回 SystemPowerReading.Unavailable(...)，界面显示「不可用」。
   绝对禁止用 Cpu.PackagePowerWatt + Gpu.PowerWatt 顶替。

6. 扩展传感器
   按能力折叠展示：CPU/GPU 利用率、内存与显存占用、显存频率、SSD 温度、
   可读取的功耗与温度限制状态。按需读取，不无限保存历史。

7. 状态真实性
   - 独显不可读时返回 GpuSnapshot.Sleeping(...)，界面显示「休眠」。
     不要返回 Unavailable——休眠与失败是不同状态。
   - 读取失败返回 SensorReading.Unavailable(...)，界面显示「不可用」。
   - 采样超时调用 MonitoringSnapshot.MarkStale(...)，
     过期数据必须标记为过期，**不得沿用上一个有效值冒充当前读数**。
   - 开启有效调试标志时记录数据来源与更新时间，界面折叠展示。
   - 不做独立趋势图。

8. 记录本机传感器覆盖与资源占用
   列出实际可读到的传感器清单、各自来源与刷新代价，作为交付物一部分。

═══ 七、已知编码陷阱（基线中已踩过，直接遵守）═══
