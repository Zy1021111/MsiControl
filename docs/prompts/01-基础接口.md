═══ 七、已知编码陷阱（基线中已踩过，直接遵守）═══

- xunit v2 不提供隐式 using，测试文件必须显式写 using Xunit;（否则报 224 个 CS0246）。
- record 陷阱：可空位置参数传裸 null 会被解析到 record 自动生成的拷贝构造函数
  （参数为不可空引用类型），触发 CS8625。必须用命名参数，例如 new(ActiveStage: null)。
- FanCurve.Validate 校验「给定顺序」；FanCurve.TryCreate 先按温度排序再校验（接受乱序）。
  两者语义差异已在 XML 文档中说明，不要混用。
- 单位换算只走 MsiControl.Core.Measurement。
  ACPI 热区温度单位是「十分之一开尔文」（3332 → 60.05 °C），是最常见的错误来源。
- 限制值只能用 PowerLimit.Native 或 PowerLimit.Custom(w)；
  构造函数私有，0、-1、极大数字在编译期即无法表达「无限」，不要试图绕过。
