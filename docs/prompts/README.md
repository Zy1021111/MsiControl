## 二、六份提示词的共同结构

每份都含七节，内容按任务定制：

1. **开工前必读** —— 共通文档 + 该任务特有的参考源码
2. **接口与能力现状** —— 该任务相关能力的实测证据与 `CapabilityLevel`
3. **你的职责** —— 具体到文件范围
4. **硬性纪律** —— 共通 8 条 + 该任务特有若干条
5. **构建方式** —— 绝对路径调用 `dotnet.exe`（本机 PATH 那份不含 SDK）
6. **交付要求** —— 必须附真实 build/test 输出
7. **已知编码陷阱** —— 基线中实际踩过的坑

## 三、各任务的关键差异（速览）

| 任务 | 相关能力的最强证据 | 该任务最关键的一条纪律 |
|---|---|---|
| 02 桌面框架 | 仅热区温度达 `Verified`，其余全为 `Detected`/`Unknown` | 绝大多数写入入口**首个版本必须禁用**，界面显示「尚未适配」是正确行为，不得用假数据填充 |
| 03 实时监控 | 热区温度 `Verified`（唯一）；CPU/GPU 精确温度来源待调查 | 独显不可读要报 `Sleeping` 而非 `Unavailable`；超时必须 `MarkStale`，**不得沿用旧值** |
| 04 风扇控制 | `Get_Fan`/`Set_Fan` 为 `Detected`；**强冷接口完全未定位** | **不得擅自执行风扇全速或校准测试**，必须先说明步骤与恢复入口 |
| 05 性能与功耗 | `Get_Power`/`Get_Range`/`Get_Device` 等为 `Detected` | 低负载功耗低于目标**不是**限制生效的证据；GPU 目标不支持时**不得静默改数** |
| 06 显卡切换 | **`Unknown` —— 无任何候选接口**，需从零调查 | 可能以「确认不支持」结案；**禁止**用设备管理器禁用显卡冒充核显模式 |
| 07 自动策略与整合 | 同全局；本机暂无任何写入达 `Verified` | 部分失败**不得宣称整组回滚成功**；不以隐藏进程冒充完全退出 |

## 四、使用须知

1. **07 是整合负责人**，按任务书 §15.1 维护 `MSI-Control.sln` 与 `Directory.Build.props`。
   其他任务若新增工程，应通知 07 代为加入解决方案，不要各自改解决方案文件。
2. **不要同时编辑同一文件**。文件归属矩阵见任务书 §15.1 与
   `docs/接口与工程约定.md` §4。
   `src/MsiControl.Hardware.Msi/Transport/**` 是最易冲突的目录，改动前必须公告。
3. **共享接口由 01 维护**。02–07 需要变更 `src/MsiControl.Core` 时先提出请求，不要直接改。
4. **`docs/design.md` 已冻结**，任何任务都不得改写其正文。
5. 各任务发现的证据统一**追加**到 `docs/hardware-evidence.md`，
   构建验证记录统一**追加**到 `docs/构建验证记录.md`，不要覆盖或新建同名文件。
