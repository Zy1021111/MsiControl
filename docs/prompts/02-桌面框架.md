═══ 三、你的职责 ═══

负责 MsiControl.Desktop 与 MsiControl.Persistence（文件归属见任务书 §15.1）。

1. 轻量 WinForms 桌面壳
   - 正常窗口：默认启动窗口，包含全部功能入口，参考 G-Helper 的紧凑布局。
     风扇曲线与性能详细参数用展开区域或独立编辑窗口，不使用宽大侧边栏与多层导航。
   - 迷你窗口：五档性能切换、显卡模式切换、CPU/GPU 温度/频率/功耗/风扇、
     有可靠数据时的整机功耗、返回正常窗口。不置顶、不含强冷按钮。
   - 两窗口共用同一份采样数据与控制核心，切换窗口不重复初始化硬件。
   - 记住窗口位置与尺寸；隐藏页面停止不必要绘制；默认只显示一个窗口。

2. 主题与可访问性
   跟随 Windows 明暗主题；支持系统 DPI 缩放；支持键盘操作。
   不使用持续发光、复杂转场与高频动画。

3. 托盘、单实例与快捷键
   - 关闭窗口进入托盘，托盘提供打开正常窗口/迷你窗口、性能模式、强冷、退出。
   - 单实例：重复启动唤醒现有窗口，不弹新窗口。
   - 全局快捷键：显示/隐藏窗口、强冷切换。可配置、可关闭；冲突时提示，不强制占用。

4. 本地配置（MsiControl.Persistence）
   - 读写、版本迁移、备份、有界轮转日志。
   - 配置内必须记录 DeviceIdentity；导入时用 IsSameBoardAs 校验机型，
     导入后必须显式应用，不自动写入硬件。
   - 日志大小有上限并轮转；导出时不包含设备序列号与不必要的个人路径。

5. 未适配能力的禁用说明
   每个不可用入口给出原因文案（未知 / 未适配 / 已确认不支持），
   不要只把按钮变灰而不解释。


═══ 四、硬性纪律 ═══

共通：
1. 仅修改本任务负责的模块。共享接口由任务 01 维护，需要变更先提出，
   不要自行修改 src/MsiControl.Core。
2. docs/design.md 已冻结，禁止修改。
3. 不猜测寄存器地址、方法参数或数值含义。
4. 不把「WMI 类存在」「方法名存在」当作「功能可用」的证据。
5. 能力未达 CapabilityLevel.Verified 前，不得开放写入。
6. 不显示虚假成功。Succeeded 必须有可追溯的确认依据。
7. 禁止引用 MSI_CPU、MSI_Power、MSI_VGA、MSI_Master_Battery、MSI_Slave_Battery。
   必须排除噪声类：MSiSCSI_*（Microsoft iSCSI）、MSIde*（Microsoft IDE）、
   ISR_MSI（= Message Signaled Interrupts，与微星品牌无关）。
8. 不自动刷固件、不关闭安全保护、不重启电脑、不修改 Intel XTU / MSI Afterburner 的配置。

本任务特有：
9. 不使用 Electron，不使用 WebView2 承载界面（任务书 §13）。
10. 仪表与曲线优先使用 WinForms 自绘控件，减少大型 UI 依赖。
    先验证 DPI、鼠标拖动与刷新开销，再决定是否引入图表库。
11. 不得绕过协调层直接写硬件。窗口只发请求、只订阅状态。
12. 「关闭到托盘」与「完全退出」是两个不同操作，界面必须区分清楚，
    不以隐藏后台进程冒充完全退出。
13. 不得把模拟数据带入默认运行流程。开发用模拟数据只能由显式开发开关启用，
    并在界面上持续标注「模拟」。


═══ 五、构建方式（必须用绝对路径）═══

本机 SDK 装在 C:\Users\yzy\.workbuddy\binaries\dotnet（安装时用了 -NoPath）。

═══ 七、已知编码陷阱（基线中已踩过，直接遵守）═══

- xunit v2 不提供隐式 using，测试文件必须显式写 using Xunit;。
- record 陷阱：可空位置参数传裸 null 会被解析到 record 自动生成的拷贝构造函数
  （参数为不可空引用类型），触发 CS8625。必须用命名参数，如 new(ActiveStage: null)。
- FanCurve.Validate 校验「给定顺序」；FanCurve.TryCreate 先按温度排序再校验。
- 单位换算只走 MsiControl.Core.Measurement（ACPI 热区是「十分之一开尔文」）。
- 限制值只能用 PowerLimit.Native 或 PowerLimit.Custom(w)，不要试图绕过私有构造。
