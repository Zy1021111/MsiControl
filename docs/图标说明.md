# MSI-Control 应用图标说明

## 1. 设计意图

图标要在一眼之内回答两个问题：**这是什么软件**、**它管什么**。

- **深色圆角瓦片**：与主界面同源的画布色（`#2A2E38 → #14161A` 垂直渐变），
  在浅色与深色任务栏上都成立，不依赖主题；圆角 22% 与界面卡片（8px/56px≈14%）
  同一语汇，略大一点以保证 16px 下仍有轮廓。
- **三叶涡轮风扇**：软件的核心动作是散热与性能调控，风扇是最短的表意符号。
  叶片是后掠梯形（根部窄、叶尖宽、整体后掠 46–52°），形成旋转方向感；
  叶尖收圆弧而不是平切，避免大尺寸下像被裁掉一角。
- **叶根与轮毂留缝**：真实风扇的转子间隙；同时保证 16px 降采样后三片不糊成实心圆。
- **冷白轮毂 + 品牌红轴心**（`#F2F4F8` / `#E4002B`）：小面积暖色点，呼应 MSI 品牌，
  也给圆盘一个视觉焦点；大尺寸可见，小尺寸退化为一个亮点，不影响识别。

配色只用了界面主题里的三种语义色（强调蓝 `#4C8DFF`、品牌红、正文白），
不引入第五种色相，避免图标与界面「两个世界」。

## 2. 规格

| 项 | 值 |
|---|---|
| 文件 | `src/MsiControl.Desktop/Resources/app.ico` |
| 尺寸档 | 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 |
| 位深 | 32 位带 alpha（圆角外透明） |
| 生成方式 | 矢量几何 + 逐尺寸 4 倍超采样（PIL），非图像模型生成 |
| 16–24px | 单独加大叶宽、收窄后掠角、去掉红轴心，只保「三叶」轮廓 |

每一档都是按目标尺寸独立渲染后降采样，不是把 256 缩下去——这是小尺寸不糊的关键。

## 3. 使用位置

| 位置 | 取用方式 |
|---|---|
| 可执行文件（资源管理器 / 任务栏 / Alt-Tab） | csproj `<ApplicationIcon>` |
| 窗口标题栏（主窗口 / 迷你 / 设置 / 风扇曲线） | `AppIcon.CreateWindowIcon()` |
| 托盘通知区域 | `AppIcon.CreateTrayIcon()`（按系统小图标尺寸取帧） |
| 主窗口应用栏品牌标 | `AppIcon.CreateBitmap(24)` |

实现见 `src/MsiControl.Desktop/Resources/AppIcon.cs`。两个要点：

1. **每次新建 `Icon` 实例**：`Form.Icon` 的生命周期归窗体，共享实例会导致第二个窗体
   拿到已释放的 GDI 句柄。
2. **位图转换不走 `Icon.ToBitmap()`**：它经 `Bitmap.FromHicon` 会把透明压成黑色，
   圆角瓦片的四角会变黑块；改用 `Graphics.DrawIcon` 绘制，保留 alpha。

## 4. 重新生成

```bash
python scripts/make_icon.py
```

脚本同时输出 `screenshots/icon_preview.png`（256 原图 + 逐尺寸 1:1 + 16/24/32 四倍放大，
含浅色底对照），用于目检小尺寸可辨性。脚本位于 WorkBuddy 工作区 `scripts/`，
调色板常量 `TILE_TOP/TILE_BOTTOM/ACCENT_*/HUB` 与 `ThemePalette` 对齐，改主题色时同步改这里。
